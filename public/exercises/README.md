# Deja tus GIFs aquí

Sube los GIFs de cada ejercicio a esta carpeta siguiendo el patrón:

```
public/exercises/bench-press.gif
public/exercises/incline-db-press.gif
public/exercises/back-squat.gif
...
```

Los slugs deben coincidir con los `id` definidos en `src/data/exercises.seed.ts`.

Mientras no exista el GIF, la card mostrará un placeholder gris (la imagen sigue siendo visible, solo con `0.2` de opacidad).
